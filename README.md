### Ultrasonic Distance Alarm

The Ultrasonic Distance Alarm is a simple safety and detection project made using a NodeMCU, an ultrasonic sensor, and a buzzer.

The ultrasonic sensor sends out ultrasonic sound waves and measures the time taken for the waves to return after hitting an object. The NodeMCU uses this information to calculate the distance between the sensor and the object.

In this project, when an object comes within a set distance of the sensor, the NodeMCU activates the buzzer. When the object moves farther away, the buzzer stops.

This project demonstrates how sensors and microcontrollers can work together to detect objects automatically. It can be used as a basic model for applications such as obstacle detection, parking assistance, and simple security alarms.
